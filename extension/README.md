# 蓝色女仆鲸鱼娘桌宠

适用于 VS Code / Cursor / Trae 的可爱桌宠插件。

## 状态

- 💤 待机 / 睡觉
- 🤔 思考中
- ⌨️ 正在写代码
- 🍚 完成任务
- 😱 遇到报错

## 命令

- `鲸鱼娘：打开鲸鱼娘桌宠`
- `鲸鱼娘：切换鲸鱼娘状态`
- `鲸鱼娘：自动循环状态`

## API

```typescript
vscode.commands.executeCommand('deepseekMaidWhale.setState', 'thinking');
```

支持：`idle` `thinking` `coding` `success` `error`
